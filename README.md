# ZRecorder
ZRecorder is a screen recorder for android built
using ACSIDE, A powerful IDE for android with real
jdk, gradle, and sdk system.

# Warning!
ZRecorder is still in the very alpha stage, you may face
instabilities, wrong aspect ratios, inaccurate quality and
app crashes.
