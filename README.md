# ZRecorder

A modern, lightweight screen recorder for Android, built entirely using **ACSIDE** — an Android IDE featuring a real JDK, Gradle, and Android SDK toolchain.

> **Project Status:** Alpha

ZRecorder is currently in active development. Features and stability are still improving, so expect bugs and unfinished functionality.

## Current Limitations

- App crashes may occur.
- Recording quality is still being tuned.
- Aspect ratio may be incorrect on some devices.
- Performance and compatibility are still under development.

## Features

- 🎥 Screen recording
- 📱 Built natively for Android
- 🚀 Developed with ACSIDE

> More features will be added as development continues.

## Building

Clone the repository:

```bash
git clone https://github.com/chappcG/ZRecorder.git
```

Open the project in **ACSIDE** or any Android Studio-compatible IDE and build using Gradle.
